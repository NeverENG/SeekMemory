## 范围

只改人格注入这一条链路，不动抽取、召回排序、预算裁剪和存储结构。

### 1. 修复人格句被 180 字截断（`recall/assemble.py`）

`_persona_sentence()` 不再复用单条记忆的 `_clean(limit=180)`：

- 只压平空白、去句末符号；
- 保留整段人格，硬上限放到 4000 字（防御性）；
- 长度由 `budget_chars` 统一约束；persona 属于 header，预算裁剪不会逐条丢它。

### 2. 新增 bootstrap 命令行入口（`scripts/bootstrap_persona.py`）

把 `docs/PERSONA_SEED.md` 定义的人格文件写进唯一人格链：

```bash
python scripts/bootstrap_persona.py --db <memory.db> --file <persona.json>
python scripts/bootstrap_persona.py --db <memory.db> --file <persona.json> --dry-run
```

- 只走 `ManagementService.bootstrap_persona()`，不碰 Source、不触发抽取；
- `--dry-run` 只校验文件（seed id/version、语料数量与文本长度）；
- 退出码：0 成功、1 文件无效或写入失败、2 参数错误。

## 验证

```bash
python3 -m unittest discover -s tests -p "test_*.py" -q
```

新增 `tests/test_persona_injection.py`：

1. **长人格完整注入**：bootstrap 3000+ 字人格后，召回文本必须包含末尾规则句；
2. **单链修订**：第二次 bootstrap 落在同一 `id`，revision 递增，seed 来源字段保留；
3. **脚本 dry-run**：只校验、不建库；
4. **缺失文件**：返回退出码 1。

|---|---:|---:|
| 人格注入长度 | 180 字（截断） | **938 字（完整）** |
| 召回注入总长 | 345 字 | **1092 字** |

## 兼容性

- 配置：无新增必填项；`budget_chars` 从 600 调到 1600 属于部署参数，不在代码里改默认值。
- 存储：无 schema 变更，`persona` 家族字段不变。
- 行为：人格句变长会占用注入预算；如长期需要更短，可裁剪人格文本或降低 `budget_chars`。

## 风险与回滚

- 风险：长人格挤占预算时，记忆条目会被裁剪；这是预算策略的预期行为，可通过 `budget_chars` 调整。
- 回滚：`git revert` 本提交即可恢复 180 字上限；人格链数据不受影响（bootstrap 是显式写入）。
