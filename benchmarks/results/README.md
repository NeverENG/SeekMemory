# Generated benchmark results

This directory preserves historical generated reports and content-free Dream triage
tradeoff snapshots. They are reproducibility artifacts, not production telemetry.
The old `latest.md` contains legacy fixture-weight/composite/character labels and
is historical, not the current regression gate. Corrected memory evaluation
writes a new ignored `.tmp/benchmarks/<run>/` directory; its fixed baseline is
`../data/memory_baseline.json`. Do not overwrite historical snapshots.

本目录保留历史生成报告及无正文的 Dream 分诊快照，不是生产遥测。
旧 latest.md 的样本权重、综合分和字数标签属于历史，不能作为当前回归门槛。
修正后的记忆评测写入新的忽略运行目录，固定基线位于上述 data 路径；不覆盖历史快照。

## Canonical files

| File | Role | Expected to change? |
|---|---|---|
| `dream_tradeoff.md` | Canonical human-readable report; generated by `benchmarks/dream_tradeoff.py` | Derived; do not hand-edit |
| `dream_tradeoff.json` | Canonical aggregate: comparison and all target snapshots | Rebuilt with the report |
| `dream_tradeoff_cc814ce.json` | Historical pre-optimization baseline | Immutable; re-record as a new dated file |
| `dream_tradeoff_d9fc248.json` | Historical merged implementation | Immutable; re-record as a new dated file |
| `dream_tradeoff_current.json` | Snapshot of the current checkout | Regenerate after relevant changes |
| `long_horizon.json` | Current 7/30/60/90-day long-horizon report; generated by `python -m benchmarks.long_horizon.run` | Regenerate after relevant changes |
| `long_horizon.md` | Human-readable dimension dashboard derived from the same run | Rebuilt with the report |
| `../data/dream_tradeoff_corpus.jsonl` | Frozen synthetic corpus | Change only with a new snapshot set and report |
| `../data/long_horizon_manifest.json` | Frozen scenario cards, targets and privacy oracles | Change only as a new manifest version |

The aggregate and the Markdown report are derived from the three per-target
snapshots. The `current` snapshot is the only one expected to change as the tree
evolves; `cc814ce` and `d9fc248` are audit history.

## Long-horizon report

`long_horizon.json` and `long_horizon.md` come from one deterministic run and
must be regenerated together:

```bash
python -m benchmarks.long_horizon.run
```

They carry `schema=seekmemory.long_horizon.v1`, the manifest digest, the harness
digest and a `reproducibility.result_digest`. The report stores counters, verdicts
and hashes only — never response text, context text, prompts or identifiers. A
scenario card is frozen before any baseline runs; do not widen a target interval
to make a result pass. Record a new manifest version instead.
